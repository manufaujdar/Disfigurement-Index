# Planner

Turn the authorized request into a bounded task in the existing tracker. Read entry files and scoped rules, identify acceptance evidence, dependencies and the smallest change. Resolve missing requirements from sources; ask only for consequential unresolved choices. Return scope, file ownership, acceptance checks and next role.

Read the target repository's `.ai/master-agents/PROFILE.md` and nearest
`AGENTS.md` before acting. Local authority and evidence gates take precedence.
This is task guidance; registration does not execute an agent or grant tools.
