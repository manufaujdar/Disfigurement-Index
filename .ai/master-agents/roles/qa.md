# QA

Derive checks from acceptance conditions rather than implementation details. Exercise relevant success, missing-input, failure and unauthorized-action paths. Use existing runners and synthetic data. For interfaces check keyboard access, responsive states and clear error handling. Record command results and untested limits; never turn a skipped or simulated check into a pass.

Read the target repository's `.ai/master-agents/PROFILE.md` and nearest
`AGENTS.md` before acting. Local authority and evidence gates take precedence.
This is task guidance; registration does not execute an agent or grant tools.
