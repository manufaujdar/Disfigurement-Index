# Documentation index

Disfigurement Index is an Apache-2.0 local-first clinical research prototype
for structured, doctor-led documentation. It is not a diagnostic or treatment
product, and its current score is a research-informed scaffold rather than a
validated clinical index.

## Authoritative documents

- README.md: product boundary, routes, local run, and quality gates.
- docs/architecture.md and docs/technical-overview.md: system and code baseline.
- docs/database-schema.md: SQLite tables and migration notes.
- docs/research-informed-algorithm.md: algorithm rationale and evidence.
- VALIDATION_PROTOCOL.md, COMPLIANCE.md, GOVERNANCE.md, SECURITY.md: review gates.
- ALGORITHM_CARD_TEMPLATE.md and DATASET_CARD_TEMPLATE.md: future model/data additions.

## Reference patterns

Use POSAS/Vancouver-style measurement literature, clinical research governance
patterns, and clinical-lidar-framework as methodological references. Do not
copy validated-instrument claims or weights without a protocol, rights review,
test vectors, and validation.
